## Overview

The `spice_simulator` module provides Streamlit-integrated functions for DC and AC SPICE analysis. These functions are designed to work with the CircuitVision Streamlit app and handle netlist preprocessing, simulation, and result visualization.

<Note>
These functions are tightly integrated with Streamlit and require `st.session_state` and logger instances. For standalone usage, consider the PySpice library directly.
</Note>

## DC Analysis

### perform_dc_spice_analysis()

Performs DC operating point analysis on a SPICE netlist with automatic preprocessing for reactance components.

```python
from src.spice_simulator import perform_dc_spice_analysis
import logging

logger = logging.getLogger('circuit_analyzer')

netlist_text = """V1 1 0 DC 12
R1 1 2 10k
R2 2 0 10k"""

results = perform_dc_spice_analysis(netlist_text, logger)
```

**Parameters:**

<ParamField path="current_netlist_content" type="str" required>
  SPICE netlist text (body only, without `.title` or `.end`)
</ParamField>

<ParamField path="app_logger" type="logging.Logger" required>
  Logger instance for debug and error messages
</ParamField>

**Behavior:**

- **Automatic reactance filtering**: Comments out capacitors (C) and inductors (L) with reactance values (e.g., `j50`, `-j100`) that would cause DC analysis errors
- **PySpice integration**: Parses netlist, runs simulation, and extracts node voltages and branch currents
- **Streamlit output**: Displays results in `st.success()` boxes with formatted tables
- **Error handling**: Returns `None` and shows `st.error()` if simulation fails

**Returns:**

<ResponseField name="success" type="bool">
  Returns `True` if simulation succeeds, `None` if it fails
</ResponseField>

<Warning>
This function has side effects: it writes directly to Streamlit UI using `st.success()`, `st.error()`, and `st.warning()`. Not suitable for non-Streamlit applications.
</Warning>

### Example DC Analysis

```python
# In app.py or Streamlit context
if st.button("Run DC Analysis"):
    netlist_str = """V1 1 0 DC 5
R1 1 2 1k
R2 2 0 1k"""
    
    result = perform_dc_spice_analysis(netlist_str, logger)
    if result:
        st.info("DC analysis completed successfully")
```

**Output Format:**

The function displays a table in Streamlit:

```
Node Voltages:
Node 1: 5.00 V
Node 2: 2.50 V
Node 0: 0.00 V (Ground)

Branch Currents:
v1: -0.005 A (supplying 5 mA)
```

## AC Analysis

### perform_ac_spice_analysis()

Performs AC frequency response analysis with automatic component value preprocessing for reactance notation.

```python
from src.spice_simulator import perform_ac_spice_analysis

# In Streamlit app context
results = perform_ac_spice_analysis(
    active_results_data=st.session_state.active_results,
    analyzer_instance=analyzer,
    current_ac_frequency_hz=1000.0,
    app_logger=logger
)
```

**Parameters:**

<ParamField path="active_results_data" type="Dict" required>
  Session state dictionary containing `'netlist'` key with netlist line dictionaries
</ParamField>

<ParamField path="analyzer_instance" type="CircuitAnalyzer" required>
  CircuitAnalyzer instance (needed for `stringify_line()` method)
</ParamField>

<ParamField path="current_ac_frequency_hz" type="float" required>
  AC analysis frequency in Hertz (e.g., 1000.0 for 1 kHz)
</ParamField>

<ParamField path="app_logger" type="logging.Logger" required>
  Logger instance for debug messages
</ParamField>

**Behavior:**

- **Reactance conversion**: Converts capacitor reactance (`-jXc`) to capacitance and inductor reactance (`jXl`) to inductance at the specified frequency
- **AC source handling**: Parses phasor notation (`magnitude:phase`) for AC voltage sources
- **PySpice simulation**: Runs single-frequency AC analysis using `circuit.ac()`
- **Streamlit visualization**: Generates matplotlib plots for magnitude and phase vs node
- **Error handling**: Shows `st.error()` and returns `None` on failure

**Returns:**

<ResponseField name="success" type="bool">
  Returns `True` if simulation and plotting succeed, `None` if it fails
</ResponseField>

<Info>
The function displays a matplotlib figure with two subplots: voltage magnitude (V) and phase (degrees) for each circuit node.
</Info>

### Reactance Conversion Examples

The function automatically converts reactance values:

**Capacitor reactance to capacitance:**
```
C1 2 0 -j159.15  →  C1 2 0 1e-6  (at 1 kHz: C = 1/(2πfXc) = 1 µF)
```

**Inductor reactance to inductance:**
```
L1 1 2 j62.83  →  L1 1 2 0.01  (at 1 kHz: L = Xl/(2πf) = 10 mH)
```

**AC voltage phasor:**
```
V1 1 0 DC 0 AC 10:30  →  AC source with 10V magnitude at 30° phase
```

### Example AC Analysis

```python
# In Streamlit app (app.py)
if st.button("Run AC Analysis"):
    ac_freq = st.number_input("Frequency (Hz)", value=1000.0, min_value=1.0)
    
    result = perform_ac_spice_analysis(
        st.session_state.active_results,
        analyzer,
        ac_freq,
        logger
    )
    
    if result:
        st.success(f"AC analysis at {ac_freq:.1f} Hz completed")
```

## Netlist Format Requirements

Both functions expect netlists in component-per-line format:

```spice
V1 1 0 DC 12
R1 1 2 1k
C1 2 0 100u
L1 2 3 10m
```

**Component format:**
```
<Type><Number> <Node+> <Node-> <Value> [AC <AC_Params>]
```

<Accordion title="Supported component types">
- **R**: Resistor (e.g., `R1 1 2 10k`)
- **C**: Capacitor (e.g., `C1 2 0 100u` or `C1 2 0 -j159`)
- **L**: Inductor (e.g., `L1 1 2 10m` or `L1 1 2 j62.83`)
- **V**: Voltage source (e.g., `V1 1 0 DC 5` or `V1 1 0 DC 0 AC 1:0`)
- **I**: Current source (e.g., `I1 0 1 DC 0.001`)
- **D**: Diode (requires model definition)
- **Q**: BJT transistor (requires model definition)
- **M**: MOSFET (requires model definition)
</Accordion>

## Integration with CircuitVision Pipeline

These functions are called from `app.py` after netlist generation:

```python
# app.py workflow
# 1. Generate netlist
netlist = analyzer.generate_netlist_from_nodes(nodes)

# 2. Enrich with Gemini
gemini_info = gemini_labels_openrouter(enum_img)
analyzer.fix_netlist(netlist, gemini_info, bbox_ids)

# 3. Convert to SPICE text
netlist_text = '\n'.join([analyzer.stringify_line(line) for line in netlist])

# 4. Run DC analysis
st.session_state.active_results['netlist_text'] = netlist_text
perform_dc_spice_analysis(netlist_text, logger)

# 5. Run AC analysis (optional)
freq = st.number_input("AC Frequency (Hz)", value=1000.0)
perform_ac_spice_analysis(
    st.session_state.active_results,
    analyzer,
    freq,
    logger
)
```

## Limitations

<Warning>
**DC Analysis:**
- Capacitors and inductors with reactance values are automatically commented out
- Open circuits (no DC path to ground) will cause simulation failure
- All nodes must eventually connect to ground (node 0)

**AC Analysis:**
- Only single-frequency analysis (not frequency sweeps)
- Reactance conversion assumes linear components
- Phase is displayed but not impedance magnitude
</Warning>

<Tip>
For frequency sweep analysis, call `perform_ac_spice_analysis()` multiple times in a loop with different frequencies and collect the results yourself.
</Tip>
