## Overview

The `spice_simulator` module provides functions for running DC operating point analysis and AC frequency response analysis on SPICE netlists generated by CircuitVision.

## DC Analysis

### perform_dc_spice_analysis()

Runs a DC operating point analysis to compute node voltages and branch currents.

```python
from src.spice_simulator import perform_dc_spice_analysis

netlist_text = """
.title Voltage Divider
V1 1 0 DC 12
R1 1 2 10k
R2 2 0 10k
.end
"""

results = perform_dc_spice_analysis(netlist_text)
print(results)
```

**Parameters:**

<ParamField path="netlist" type="str" required>
  Complete SPICE netlist text including `.title` and `.end` directives
</ParamField>

**Returns:**

<ResponseField name="results" type="Dict[str, Any] | None">
  Analysis results dictionary or None if simulation fails:
  
  <Expandable title="result structure">
    <ResponseField name="nodes" type="Dict[str, float]">
      Node voltages (e.g., `{'1': 12.0, '2': 6.0, '0': 0.0}`)
    </ResponseField>
    <ResponseField name="branches" type="Dict[str, float]">
      Branch currents (e.g., `{'v1': -0.0006}`)
    </ResponseField>
    <ResponseField name="circuit" type="PySpice.Spice.Netlist.Circuit">
      PySpice circuit object
    </ResponseField>
    <ResponseField name="simulator" type="PySpice.Spice.NgSpice.Shared.NgSpiceShared">
      PySpice simulator instance
    </ResponseField>
    <ResponseField name="analysis" type="PySpice.Spice.Netlist.Analysis">
      PySpice analysis object with detailed results
    </ResponseField>
  </Expandable>
</ResponseField>

**Example Output:**

```python
{
    'nodes': {
        '1': 12.0,      # Node 1: 12V (voltage source)
        '2': 6.0,       # Node 2: 6V (voltage divider midpoint)
        '0': 0.0        # Node 0: Ground
    },
    'branches': {
        'v1': -0.0006   # Current through V1: -0.6 mA (negative = sourcing)
    },
    'circuit': <Circuit object>,
    'simulator': <NgSpiceShared object>,
    'analysis': <Analysis object>
}
```

<Note>
Node '0' is always ground (0V). Branch currents are negative when the source is supplying current.
</Note>

### DC Analysis Error Handling

```python
try:
    results = perform_dc_spice_analysis(netlist_text)
    if results is None:
        print("Simulation failed - check netlist syntax")
    else:
        print(f"Node 2 voltage: {results['nodes']['2']:.3f}V")
except Exception as e:
    print(f"SPICE error: {e}")
```

**Common Errors:**

- **Missing ground node (0)**: Every netlist must have at least one node connected to '0'
- **Syntax errors**: Component lines must follow SPICE format (e.g., `R1 1 2 10k`)
- **Open circuits**: All nodes must have a DC path to ground
- **Missing values**: Components must have numeric values (not `None`)

<Warning>
The netlist must include `.title` as the first line and `.end` as the last line for PySpice compatibility.
</Warning>

## AC Analysis

### perform_ac_spice_analysis()

Runs an AC small-signal frequency response analysis.

```python
from src.spice_simulator import perform_ac_spice_analysis

netlist_text = """
.title RC Low-Pass Filter
V1 1 0 DC 0 AC 1
R1 1 2 1k
C1 2 0 1u
.end
"""

results = perform_ac_spice_analysis(
    netlist=netlist_text,
    start_frequency=10,
    stop_frequency=100e3,
    number_of_points=100,
    variation='dec'
)
```

**Parameters:**

<ParamField path="netlist" type="str" required>
  SPICE netlist with AC source(s) specified
</ParamField>

<ParamField path="start_frequency" type="float" default="10">
  Starting frequency in Hz
</ParamField>

<ParamField path="stop_frequency" type="float" default="100e3">
  Stopping frequency in Hz
</ParamField>

<ParamField path="number_of_points" type="int" default="100">
  Number of frequency points to simulate
</ParamField>

<ParamField path="variation" type="str" default="dec">
  Frequency sweep type: 'dec' (logarithmic) or 'lin' (linear)
</ParamField>

**Returns:**

<ResponseField name="results" type="Dict[str, Any] | None">
  Analysis results dictionary or None if simulation fails:
  
  <Expandable title="result structure">
    <ResponseField name="frequency" type="np.ndarray">
      Frequency points (Hz)
    </ResponseField>
    <ResponseField name="nodes" type="Dict[str, np.ndarray]">
      Complex node voltages vs frequency (e.g., `{'1': array([...]), '2': array([...])}`)
    </ResponseField>
    <ResponseField name="magnitude" type="Dict[str, np.ndarray]">
      Voltage magnitude (linear) for each node
    </ResponseField>
    <ResponseField name="magnitude_db" type="Dict[str, np.ndarray]">
      Voltage magnitude in dB for each node
    </ResponseField>
    <ResponseField name="phase" type="Dict[str, np.ndarray]">
      Phase in degrees for each node
    </ResponseField>
    <ResponseField name="circuit" type="PySpice.Spice.Netlist.Circuit">
      PySpice circuit object
    </ResponseField>
  </Expandable>
</ResponseField>

**Example Output:**

```python
{
    'frequency': array([10, 15.85, 25.12, ..., 100000]),  # 100 points
    'nodes': {
        '1': array([1+0j, 1+0j, ...]),       # AC source: constant 1V
        '2': array([0.99-0.01j, 0.98-0.02j, ...])  # Output: attenuated & phase shifted
    },
    'magnitude': {
        '1': array([1.0, 1.0, ...]),         # |V1|: 1V at all frequencies
        '2': array([0.99, 0.98, ..., 0.01])  # |V2|: rolls off at high freq
    },
    'magnitude_db': {
        '1': array([0.0, 0.0, ...]),         # 20*log10(1) = 0 dB
        '2': array([-0.09, -0.18, ..., -40]) # Rolls off to -40 dB
    },
    'phase': {
        '1': array([0.0, 0.0, ...]),         # 0° phase
        '2': array([-0.58, -1.17, ..., -89.9])  # Phase lag increases with freq
    },
    'circuit': <Circuit object>
}
```

### Plotting AC Results

```python
import matplotlib.pyplot as plt
import numpy as np

results = perform_ac_spice_analysis(netlist_text)

if results:
    freq = results['frequency']
    vout_db = results['magnitude_db']['2']  # Output node
    phase = results['phase']['2']
    
    fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8))
    
    # Bode magnitude plot
    ax1.semilogx(freq, vout_db)
    ax1.set_ylabel('Magnitude (dB)')
    ax1.set_title('Frequency Response')
    ax1.grid(True, which='both')
    
    # Bode phase plot
    ax2.semilogx(freq, phase)
    ax2.set_xlabel('Frequency (Hz)')
    ax2.set_ylabel('Phase (degrees)')
    ax2.grid(True, which='both')
    
    plt.tight_layout()
    plt.savefig('bode_plot.png')
```

<Tip>
Use `variation='dec'` with `number_of_points=10` per decade for smooth logarithmic plots. For a 10 Hz to 100 kHz sweep, use `number_of_points=40` (4 decades × 10 points/decade).
</Tip>

## Netlist Requirements

### DC Netlist Format

```spice
.title My DC Circuit
V1 1 0 DC 12          # Voltage source: 12V between nodes 1 and 0
R1 1 2 10k            # Resistor: 10kΩ between nodes 1 and 2
R2 2 0 10k            # Resistor: 10kΩ between nodes 2 and 0 (ground)
.end
```

### AC Netlist Format

```spice
.title My AC Circuit
V1 1 0 DC 0 AC 1      # AC source: 0V DC offset, 1V AC amplitude
R1 1 2 1k
C1 2 0 1u
.end
```

<Accordion title="SPICE component syntax reference">
**Resistors:**
```
R<name> <node1> <node2> <value>
R1 1 2 10k
R2 3 0 4.7M
```

**Capacitors:**
```
C<name> <node1> <node2> <value>
C1 2 0 100u
C2 5 6 22n
```

**Inductors:**
```
L<name> <node1> <node2> <value>
L1 3 4 10m
```

**Voltage Sources:**
```
V<name> <+node> <-node> DC <dc_value> [AC <ac_amplitude> [<phase>]]
V1 1 0 DC 12           # DC only
V2 2 0 DC 0 AC 1       # AC with 0V DC offset
V3 3 0 DC 5 AC 2 90    # AC with phase
```

**Current Sources:**
```
I<name> <+node> <-node> DC <value>
I1 0 1 DC 1m           # 1 mA from node 0 to node 1
```
</Accordion>

## Complete Example: Voltage Divider Analysis

```python
from src.spice_simulator import perform_dc_spice_analysis
from src.circuit_analyzer import CircuitAnalyzer
from src.utils import gemini_labels_openrouter
import cv2

# Step 1: Analyze circuit diagram
analyzer = CircuitAnalyzer()
image = cv2.imread('voltage_divider.png')
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# ... (detection, segmentation, topology analysis)

# Step 2: Generate netlist
nodes = analyzer.get_node_connections(image_rgb, sam_mask, bboxes)
netlist = analyzer.generate_netlist_from_nodes(nodes)

# Step 3: Enrich with Gemini
enum_img, bbox_ids = analyzer.enumerate_components(image_rgb, bboxes)
gemini_info = gemini_labels_openrouter(enum_img)
analyzer.fix_netlist(netlist, gemini_info, bbox_ids)

# Step 4: Convert to SPICE text
netlist_text = '.title Voltage Divider Circuit\n'
for line in netlist:
    netlist_text += analyzer.stringify_line(line) + '\n'
netlist_text += '.end'

# Step 5: Simulate
results = perform_dc_spice_analysis(netlist_text)

if results:
    print("\nNode Voltages:")
    for node, voltage in results['nodes'].items():
        print(f"  Node {node}: {voltage:.3f} V")
    
    print("\nBranch Currents:")
    for branch, current in results['branches'].items():
        print(f"  {branch}: {current*1000:.3f} mA")
else:
    print("Simulation failed")
```
