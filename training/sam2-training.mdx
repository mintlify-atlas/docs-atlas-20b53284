## Overview

CircuitVision uses a **fine-tuned Segment Anything Model 2 (SAM 2)** for precise segmentation of conductive traces in circuit diagrams. Through **LoRA (Low-Rank Adaptation)** fine-tuning, the model achieves an impressive **98.7% accuracy** on circuit segmentation from a dataset of only **267 images**.

## Why SAM 2 for Circuits?

The Segment Anything Model 2 is ideal for circuit analysis because:

- **Zero-shot capability**: Pretrained on diverse image types
- **High precision**: Generates detailed binary masks of traces
- **Efficient fine-tuning**: LoRA enables training with limited data
- **Automatic prompting**: No manual point/box prompts needed for our use case

## LoRA Fine-Tuning Strategy

### What is LoRA?

LoRA (Low-Rank Adaptation) is a parameter-efficient fine-tuning technique that:

- **Freezes** the original model weights
- **Injects** trainable low-rank matrices into attention layers
- **Reduces** the number of trainable parameters by >90%
- **Enables** training on smaller datasets with less GPU memory

### LoRA Hyperparameters

```python
self.sam2_model = get_modified_sam2(
    model_cfg_path=sam2_config_path,
    checkpoint_path=sam2_base_checkpoint_path,
    device=device,
    use_high_res_features=True,
    use_peft=True,
    lora_rank=4,              # Low rank for efficiency
    lora_alpha=16,            # Scaling factor
    lora_dropout=0.3,         # Prevent overfitting
    lora_target_modules=base_parts + added_parts,
    use_wrapper=True,
    trainable_embedding_r=4,  # Trainable embedding rank
    use_refinement_layer=True,
    refinement_kernels=[3, 5, 7, 11],  # Multi-scale refinement
    kernel_channels=2,
    weight_dice=0.5,          # Loss weights
    weight_focal=0.4,
    weight_iou=0.3,
    weight_freq=0.1,
    focal_alpha=0.25
)
```

<Note>
**Key Parameters:**
- `lora_rank=4`: Balance between capacity and efficiency
- `lora_alpha=16`: Controls the magnitude of LoRA updates
- `lora_dropout=0.3`: Regularization for small dataset
- `use_refinement_layer=True`: Custom layer for better trace boundaries
</Note>

## Training Pipeline

### Dataset Preparation

The SAM 2 model was trained on **267 carefully annotated circuit images** with:

- **Binary masks**: White traces on black background
- **Diverse sources**: Hand-drawn, printed schematics, photographs
- **Various complexities**: Simple to complex multi-component circuits
- **Data augmentation**: Rotation, scaling, brightness adjustments

<Info>
Despite the small dataset size, LoRA fine-tuning enabled 98.7% accuracy, demonstrating excellent data efficiency.
</Info>

### Loss Function

A composite loss function optimizes multiple objectives:

```python
total_loss = (
    0.5 * dice_loss +      # Overlap-based loss
    0.4 * focal_loss +     # Handles class imbalance
    0.3 * iou_loss +       # IoU-based metric
    0.1 * freq_loss        # Frequency domain loss
)
```

- **Dice Loss (0.5)**: Measures overlap between prediction and ground truth
- **Focal Loss (0.4)**: Focuses on hard-to-segment regions
- **IoU Loss (0.3)**: Directly optimizes intersection-over-union
- **Frequency Loss (0.1)**: Preserves fine details in trace patterns

### Training Workflow

1. **Initialize** base SAM 2.1 Hiera-Large model
2. **Inject** LoRA adapters into target modules
3. **Freeze** original SAM 2 weights
4. **Train** only LoRA parameters and refinement layers
5. **Validate** on held-out circuit images
6. **Save** best checkpoint based on mIoU (mean Intersection over Union)

### Refinement Layer

A custom multi-scale refinement layer improves trace boundary detection:

```python
refinement_kernels = [3, 5, 7, 11]  # Multi-scale kernels
kernel_channels = 2
```

This layer processes the mask at multiple scales to:
- Smooth jagged edges
- Fill small gaps in traces
- Remove spurious noise

## Intelligent Cropping Integration

Before SAM 2 segmentation, CircuitVision performs **intelligent YOLO-based cropping**:

1. **Detect components** with YOLO
2. **Calculate bounding box** encompassing all components
3. **Crop image** to focus on circuit area
4. **Remove background noise** significantly
5. **Apply SAM 2** to cropped region for better accuracy

<Info>
This two-stage approach (YOLO crop → SAM 2 segment) is a key innovation that boosts downstream accuracy in node and connection analysis.
</Info>

## Training Tips

<Accordion title="Best Practices for SAM 2 Fine-Tuning">

### Dataset Considerations
- **Quality over quantity**: 267 high-quality annotations outperform 1000s of poor ones
- **Mask precision**: Ensure binary masks accurately trace conductive paths
- **Diversity**: Include various circuit types, drawing styles, and image qualities
- **Validation split**: Hold out representative samples for unbiased evaluation

### Hyperparameter Tuning
- **LoRA rank**: Start with 4; increase if underfitting (more capacity)
- **Dropout**: Use 0.2-0.4 for small datasets to prevent overfitting
- **Loss weights**: Adjust based on dataset characteristics (e.g., increase focal if class imbalance)
- **Learning rate**: Lower than full fine-tuning (typically 1e-4 to 1e-5)

### Refinement Layer
- Experiment with kernel sizes based on typical trace widths
- More kernels = better multi-scale but slower inference
- Tune `kernel_channels` for capacity vs. speed trade-off

### Avoiding Overfitting
- Monitor validation metrics closely
- Use early stopping
- Apply data augmentation (rotation, flip, brightness)
- Keep LoRA rank low initially

</Accordion>
