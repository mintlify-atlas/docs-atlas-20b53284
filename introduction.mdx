    Get started in minutes
  </h2>
  <p className="text-base text-gray-600 dark:text-gray-400 mb-8">
    Follow these steps to set up CircuitVision and analyze your first circuit diagram.
  </p>

  <Steps>
    <Step title="Install dependencies">
      Clone the repository and install required Python packages:
      
      ```bash
      git clone https://github.com/JKc66/CircuitVision.git
      cd CircuitVision
      pip install -r requirements.txt
      ```
    </Step>

    <Step title="Download model weights">
      Run the provided script to download pre-trained YOLOv11 and SAM 2.1 models:
      
      ```bash
      python download_models.py
      ```
      
      This creates `models/YOLO` and `models/SAM2` directories with the necessary fine-tuned weights.
    </Step>

    <Step title="Configure API keys">
      Set your Google Gemini API key for component value extraction:
      
      ```bash
      export GEMINI_API_KEY="your-api-key-here"
      ```
      
      <Tip>Get a free Gemini API key at [Google AI Studio](https://aistudio.google.com/app/apikey)</Tip>
    </Step>

    <Step title="Launch the application">
      Start the Streamlit web interface:
      
      ```bash
      streamlit run app.py
      ```
      
      Upload a circuit diagram image and watch CircuitVision detect components, analyze topology, and generate a SPICE netlist automatically.
    </Step>
  </Steps>
</div>
